The machine catches breakage you can measure

  • External and missing resources

    HTML, CSS, images, video and fonts.

  • Horizontal overflow

    At every reference width.

  • Controls without an accessible name

    Buttons, links and input fields.

  • Broken theme and print

    Chromium checks theme switching and PDF output.
