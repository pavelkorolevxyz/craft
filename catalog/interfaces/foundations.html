Правило

Onest используется в тексте и управлении. Geologica остаётся в коротких заголовках и числах. Размер не меняется плавно между контрольными ширинами.

Доступность

Уровень заголовка задаёт структуру документа, а не внешний размер. На странице остаётся один h1.

Ритм

Внутри смысловой группы расстояние меньше, чем между соседними группами.

Границы

Размеры шрифта, линий и иконок не подгоняются под шкалу интервалов.

Вертикальный поток

Одинаковый зазор между последовательными блоками без управления их внутренними полями.

Последовательность

Первый абзац не получает внешнего верхнего поля.

Расстояние добавляется только между соседними элементами.

Разметка примера

Применение

Используй для вертикальной группы разнородных элементов. Для однородного списка выбирай семантический список.

Настройка

Локальный зазор задаётся переменной --stack-gap из шкалы отступов.

Публичный контракт
Корень.stack
Зазор--stack-gap

Секция

Самостоятельная часть документа с заголовком, пояснением и естественным потоком содержания.

Название секции

Пояснение формулирует вопрос, на который отвечает содержание ниже.

Содержание течёт по высоте и может переходить между печатными страницами.

Разметка примера

Варианты

Плотная секция использует .section--tight. Акцентная секция допустима для одного ключевого вывода.

Структура

Уровень заголовка следует структуре итогового документа. Вложенные секции не заменяются визуальными карточками.

Публичный контракт
Корень.section
Заголовок.section-head
Модификаторы.section--tight, .section--accent

Разметка примера

Применение

Компонент нужен только для сравнимых панелей с одинаковой внутренней структурой.

Совместимость

При поддержке subgrid ряды синхронизируются. Без неё каждая панель остаётся читаемой самостоятельно.

Публичный контракт
Группа.equal-panels
Панель.equal-panel
Ряды__head, __body, __foot

Длинный текст

Читаемая колонка для документации, пояснений и последовательного аргумента.

Короткий заголовок

Текст ограничен семьюдесятью двумя знаками в строке. Интерфейс вокруг него может занимать всю доступную ширину.

Встроенный код отличается шрифтом и плоскостью, а ссылка остаётся акцентной.

  • Один тезис на пункт.
  • Естественная высота без внутренней прокрутки.
Разметка примера

Применение

Для справки и длинного объяснения. Таблицы и графики выходят из текстовой колонки в самостоятельную секцию.

Печать

Поток не получает фиксированной высоты и естественно переносится между страницами.
