Сравнивает однородные записи по устойчивому набору колонок.

HTML-фрагмент
Источник
fragments/data-table.html
Корень
.data-table

Разметка примера

Применение

Одна колонка отвечает на один вопрос. Сортировка, фильтры и пагинация добавляются только под конкретную задачу.

Доступность

Таблица получает подпись, заголовки используют th. Горизонтальная прокрутка доступна с клавиатуры.

Публичный контракт
Корень.data-table
Прокрутка.table-scroll
Варианты.data-table--sticky, .data-table__sort, .data-table__detail

Разметка примера

Применение

События идут от раннего к позднему или наоборот, но порядок не меняется внутри одной ленты.

Доступность

Метка цвета дополняется заголовком. Машиночитаемое время задаётся атрибутом datetime.

Публичный контракт
Корень.timeline
Части__mark, __time, __title

Блок кода

Локальный исходный код с подписью файла и копированием.

Тип
HTML-фрагмент
Источник
fragments/code-block.html
Механика

Разметка примера

Применение

Подпись называет источник. Моноширинный шрифт не используется в обычных значениях и метаданных.

Механика

Кнопка ссылается на код через data-copy-target; подпись меняется без скачка ширины.

Публичный контракт
Корень.code-block
Кнопка.code-block__copy
Хукdata-copy-target

Разметка примера

Применение

Все полосы используют один максимум. Значение дублируется числом и не считывается только по длине.

Движение

Появление полосы отключается при prefers-reduced-motion.

Публичный контракт
Корень.bar-list
Части.bar__head, .bar__track, .bar__fill
Значение--value

Ключ ряда

Связывает подпись ряда с цветом или типом линии рядом с графиком.

Тип
CSS-примитив
Источник
theme.css
Корень
.series-key
ПриоритетныйСравнениеБазовый
Разметка примера

Применение

Ключ ставится рядом с графиком. Если ряд можно подписать прямо у линии, отдельная легенда не нужна.

Доступность

Подпись остаётся явной: цвет не является единственным идентификатором ряда.

Публичный контракт
Корень.series-key
Образец--swatch
