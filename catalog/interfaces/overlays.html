Оверлеи

Верхний слой используется только для короткого действия, которое нельзя безопасно выполнить в обычном потоке.

Диалог

Нативное модальное окно для подтверждения или короткого ограниченного ввода.

Основное содержание страницы остаётся в обычном потоке.

Подтвердить действие

Коротко объясните необратимое последствие.

Разметка примера

Когда использовать

Для необратимого подтверждения или короткого действия, которому нужен верхний слой. Справка и дополнительные параметры раскрываются в потоке.

Клавиатура

Нативный dialog удерживает фокус и закрывается клавишей Escape. Скрипт возвращает фокус кнопке вызова.
