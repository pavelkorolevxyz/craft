Формы

Нативные элементы ввода с общей высотой, прямыми углами и явными подписями.

Поле

Связывает подпись, управление, подсказку и ошибку в одну вертикальную группу.

Тип
HTML-фрагмент
Источник
fragments/field.html
Корень
.field

Короткое правило заполнения.

Разметка примера

Ошибка

При ошибке управление получает aria-invalid="true", а сообщение связывается через aria-describedby.

Подсказка

Подсказка объясняет правило до ввода. Пустые подсказка и ошибка не занимают место.

Публичный контракт
Части.field__label, .field__hint, .field__error
Состояниеaria-invalid, aria-describedby

Однострочный ввод

Короткое текстовое, числовое или поисковое значение.

Тип
нативный элемент
Источник
theme.css
Элемент
input
Разметка примера

Выбор типа

Используй наиболее точный нативный type. Он определяет клавиатуру, проверку и объявление значения.

Состояния

disabled исключает поле из формы. readonly оставляет значение доступным для выделения.

Публичный контракт
Высота40 px
Состоянияdisabled, readonly, aria-invalid

Многострочный ввод

Текст, которому заранее требуется несколько строк.

Тип
нативный элемент
Источник
theme.css
Элемент
textarea
Разметка примера

Применение

Не используй многострочное поле для одного короткого значения. Начальную высоту задаёт rows.

Доступность

Видимая подпись обязательна. Ограничение длины сообщается до поля и программно.

Публичный контракт
Минимальная высота96 px
Изменение размератолько по вертикали

Выбор из списка

Одно известное значение из набора, который не нужно видеть постоянно.

Тип
CSS-примитив
Источник
theme.css
Корень
.select-control
Разметка примера

Применение

Для двух коротких режимов лучше сегментированный выбор. Длинный набор остаётся нативным select.

Клавиатура

Нативный список сохраняет поиск по первой букве и системное управление.

Публичный контракт
Обёртка.select-control
Иконка.select-control__icon

Флажок

Независимый двоичный выбор или выбор нескольких значений.

Тип
нативный элемент
Источник
theme.css
Обёртка
.check
Разметка примера

Применение

Подпись описывает состояние после выбора. Несколько флажков объединяются видимой легендой.

Состояния

Поддерживаются checked, indeterminate и disabled.

Публичный контракт
Обёртка.check
Группа.check-group

Радиогруппа

Один обязательный выбор из короткого набора видимых вариантов.

Тип
нативная группа
Источник
theme.css
Корень
.check-group
Способ
Разметка примера

Применение

Все варианты видны одновременно. Для длинного набора используй список выбора.

Клавиатура

Общее имя связывает группу; fieldset и legend дают ей доступное название.

Публичный контракт

Переключатель

Немедленно включает или выключает режим без отдельного сохранения.

Тип
CSS-примитив
Источник
theme.css
Корень
.switch
Разметка примера

Применение

Не используй переключатель, если изменение требует кнопки «Сохранить». В таком случае нужен флажок.

Доступность

Нативный флажок получает role="switch" и остаётся внутри видимой подписи.

Публичный контракт
Корень.switch
Рольrole="switch"

Источник

Разметка примера

Применение
