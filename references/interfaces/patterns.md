# Геометрия страницы

Стартер пуст. Выбери режим по задаче, затем добавляй только нужные фрагменты. Один материал может сочетать режимы.

| Режим | Когда использовать | Геометрия и основа |
|---|---|---|
| Документ | Последовательное чтение отчёта или исследования | `page-head`, секции с `.document-band`, текст `.prose`. Самостоятельный ограниченный блок использует `.document-block`, с рамкой `.document-block--framed` |
| Поверхность данных | Сравнение значений, поиск отклонений | `workspace-head`, полноширинная таблица или график. Параметры стоят над областью, которую меняют. Метрики поддерживают вывод, не образуют заставку |
| Рабочая поверхность | Выбор записи, редактирование, работа с деталями | `workspace-head` и `split-workspace`. Главная рабочая область начинается на первом экране. На узком экране колонки идут последовательно с общей прокруткой |

Не центрируй инструмент как текстовый документ. Не дели страницу пополам только потому, что есть два блока. `split-workspace` нужен для связанных основной области и подробностей. После явного выбора на мобильном доведи пользователя до деталей, но не прокручивай страницу на каждом нажатии стрелки. Механику выбора смотри в [навигации](components/navigation.md).

## Подбор фрагмента

Идентификатор в `compose.py` совпадает с именем HTML-файла без расширения. Контракт получи через `--fragment <id> --list-placeholders`.

| Содержимое или действие | Фрагменты | Справочник |
|---|---|---|
| Заголовок, раздел, метрики, две связанные области | `page-head`, `workspace-head`, `section`, `metric-strip`, `split-workspace` | [Каркас](components.md) |
| Поле с подписью, подсказкой и ошибкой | `field` | [Формы](components/forms.md) |
| Точная таблица, поля объекта, история, код | `data-table`, `kv-list`, `timeline`, `code-block` | [Данные](components/data.md) |
| Отсутствие результата, уведомление, подтверждение | `empty-state`, `notice`, `dialog` | [Обратная связь](components/feedback.md) |
| Параметры, разделы, вкладки, страницы, шаги | `filter-bar`, `section-nav`, `tabs`, `pagination`, `breadcrumbs`, `steps` | [Навигация](components/navigation.md) |

Сравниваемые значения выравнивай по общей строке или колонке. Растущий поток получает всю строку вместо короткой соседней панели. Рабочие области разделяют заголовки и линия; фоны берутся из готовой темы, без отдельных оттенков для каждой панели. Правила размеров и состояния управления находятся в [грамматике](design-language.md).

## Локальные данные

Небольшой набор встрои в HTML или локальный скрипт. Большие данные при `file://` подключай обычным `<script>`, не `fetch()` локального JSON. JavaScript нужен реальному взаимодействию, не статической композиции. URL или `localStorage` сохраняют состояние только если это помогает повторной работе.
