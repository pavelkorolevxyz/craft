# Данные интерфейса

## Метки и статусы

| Конструкция | Назначение |
|---|---|
| `.tag`, `.tag-list` | Категория, команда, версия. `.tag--accent` выделяет один вид меток |
| `.tag--ok`, `.tag--warn`, `.tag--error` | Статусная колонка: рамка и подпись одного цвета, высота общая |
| `.status`, `.status--ok`, `.status--warn`, `.status--error` | Состояние в тексте: цветная точка и нейтральная подпись |
| `.surface-tint`, `.surface-tint--error` | Тихое выделение строки через прозрачный `--accent-tint` или `--error-tint` |

```html
<span class="status status--error">Ошибка</span>
<span class="tag">Ожидает</span>
```

Ожидаемые и промежуточные состояния нейтральны. Цвет нужен состоянию, требующему решения. Свой тон задаётся локальным `--status`, не новой точкой или цветом ряда данных. Не объединяй состояние проверки и состояние ревью в одной колонке. Заголовок называет ровно тот смысл, который лежит в ячейках.

## Таблицы

`data-table.html` создаёт `.data-table` внутри `.table-scroll`. Текст и его заголовок выровнены влево, числа и их заголовок вправо. Укажи единицы и одинаковую точность; добавь `caption`, если назначение не объясняет заголовок секции. `.total` обозначает итоговую строку.

Числовая матрица с короткими ячейками сохраняет колонки и горизонтальную прокрутку на узком экране. Текстовая таблица разворачивается в записи:

```html
<table class="data-table data-table--records">
  <thead><tr><th>Проверка</th><th>Состояние</th></tr></thead>
  <tbody><tr><td data-label="Проверка">Вход</td><td data-label="Состояние">Ожидает</td></tr></tbody>
</table>
```

Каждый `data-label` повторяет соответствующий `th`. Главное поле остаётся строкой, остальные подписанными парами. Не теряй поля молча и не повторяй их сразу в записи и соседней сводке. Вторичные сведения можно перенести в подробности.

Строки статичны по умолчанию. Для выбора записи нужны `data-interactive`, `tabindex="0"`, `aria-selected` и рабочие обработчики мыши и клавиатуры. Наведение и выбор уже оформлены темой.

Для сортировки используй `<th aria-sort="ascending">` с кнопкой `.data-table__sort` и встроенной SVG-стрелкой. `aria-sort` находится только на текущей колонке. Место под стрелку резервируется во всех сортируемых заголовках. `.data-table--sticky` закрепляет шапку, в печати она возвращается в поток. Кнопка подробностей имеет `aria-expanded` и `aria-controls`, подробность живёт в соседней `.data-table__detail`.

## Пары значений

`kv-list.html` подходит, если поля одного объекта читают подряд, не сравнивают записи между собой.

```html
<div class="kv-block">
  <h3 class="kv-block__title">Параметры</h3>
  <dl class="kv-list kv-list--lined"><dt>Версия</dt><dd>2.4.1</dd><dt>Окружение</dt><dd>Предпродакшен</dd></dl>
</div>
```

`.kv-list--lined` добавляет разделители. На узком экране пара разворачивается в две строки и остаётся неразрывной.

## Графики и полосы

Выбирай форму по данным: линия для изменения и событий, столбцы для категорий, тепловая карта для распределения, кольцо для долей целого. Небольшому набору достаточно HTML, CSS или SVG. У графика есть заголовок, подписи, единицы и доступное текстовое резюме.

- Столбцы начинаются с нуля. Если диапазон другой, отметь это явно. Значение дублируется текстом, длину полосы задаёт блочный элемент.
- Ряды идут по ролям `--data-red`, `--data-neutral`, `--data-blue`, `--data-amber`, `--data-green`. Если красный уже означает превышение порога, начни с нейтрального. Не используй более пяти рядов.
- Кольцо ограничено пятью долями, проценты подписаны рядом. Тепловая карта объясняет направление яркости и не заменяет точные числа, необходимые для решения.
- Линия имеет толщину 1,5 px и сплошной цвет. В SVG используй `vector-effect="non-scaling-stroke"`. При `preserveAspectRatio="none"` вынеси подписи в HTML, чтобы текст не деформировался.
- `.series-key` с `style="--swatch: var(--data-blue)"` связывает название с рядом.
- Интерактивный график получает фокус, управление стрелками и живую область со значением. Статический не притворяется интерактивным.
- Окрашивай изменение только при однозначном смысле направления. Рост трафика сам по себе не хорош и не плох.

```html
<div class="bar-list" aria-label="Нагрузка">
  <div class="bar"><div class="bar__head"><span>Основной поток</span><strong>82%</strong></div>
    <div class="bar__track"><div class="bar__fill" style="--value:82%"></div></div>
  </div>
</div>
```

## Выполнение и события

Прогресс показывает завершённость одной операции, `.bar` сравнивает величины.

```html
<div class="progress">
  <div class="progress__head"><span>Обработано</span><strong>420 из 900</strong></div>
  <div class="progress__track"><span class="progress__fill" style="--value:47%"></span></div>
</div>
```

Если доля неизвестна, `.progress--indeterminate` сообщает только факт работы. Рядом остаётся текст, поскольку при уменьшении движения полоса останавливается.

`timeline.html` показывает хронологию событий с единым форматом времени. `.timeline__mark` занимает свою колонку; `.timeline__time`, `.timeline__title` и пояснение выровнены по общему левому краю во второй колонке. Линия соединяет точки и не разрывается длинной записью. Для конечной последовательности действий используй [шаги](navigation.md).

## Код

`code-block.html` создаёт `.code-block` с `.code-block__head`, `pre` и кнопкой `.code-block__copy`. Кнопка с `data-copy="#id"` указывает на источник; `copy.js` копирует текст и на две секунды переключает `.button--stable` через `aria-pressed`. Для `file://` предусмотрено копирование через выделение, если буфер обмена недоступен.

Подпись источника набирается обычным шрифтом. Моноширинный текст только внутри кода, кнопка в печати скрыта.
