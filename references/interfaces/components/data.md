# Представление данных

Эти компоненты показывают значения, состав и историю. Все они рассчитаны на реальные данные: подпись без числа и число без единицы измерения не работают.

## Метка категории

```html
<div class="tag-list">
  <span class="tag">Интерфейс</span>
  <span class="tag tag--accent">Приоритет</span>
</div>
```

`.tag` называет принадлежность: направление, команду, версию, вид записи. Это не состояние, поэтому метка остаётся нейтральной и не берёт сигнальный цвет. `.tag--accent` достаётся одному виду меток на странице.

Не подменяй метками статус: у статуса есть три тона и точка, у метки — только текст.

## Подписанное состояние в колонке

```html
<span class="state-label state-label--warn">на проверке</span>
```

`.state-label` собирает статусную колонку: одинаковая высота, цветная рамка, явный текст, содержимое по центру. Заливку лейбл не берёт, иначе колонка превращается в ряд плашек. Обычное состояние внутри строки описания по-прежнему показывает точка `.status`.

## Пары «поле — значение»

```html
<div class="kv-block">
  <h3 class="kv-block__title">Параметры запуска</h3>
  <dl class="kv-list kv-list--lined">
    <dt>Версия</dt><dd>2.4.1</dd>
    <dt>Окружение</dt><dd>Предпродакшен</dd>
  </dl>
</div>
```

Список пар заменяет таблицу из двух колонок, когда записи не сравнивают между собой, а читают подряд. `.kv-list--lined` добавляет разделители, если пар много. На узком экране пара разворачивается в две строки и остаётся неразрывной.

Фрагмент — `kv-list.html`.

## Ход выполнения

```html
<div class="progress">
  <div class="progress__head"><span>Обработано</span><strong>420 из 900</strong></div>
  <div class="progress__track"><span class="progress__fill" style="--value: 47%"></span></div>
</div>
```

Определённый прогресс всегда дублируется числом: полоса показывает соотношение, число отвечает на вопрос «сколько осталось». Если долю посчитать нельзя, бери `.progress--indeterminate` — она сообщает только факт работы. При уменьшении движения такая полоса останавливается, поэтому рядом должен быть текст о происходящем.

Не путай прогресс с полосой данных `.bar`: полоса сравнивает величины между собой, прогресс показывает завершённость одной операции.

## Лента событий

```html
<ol class="timeline" aria-label="История задачи">
  <li>
    <span class="timeline__mark" aria-hidden="true"></span>
    <span class="timeline__time">14:02</span>
    <div><span class="timeline__title">Запуск проверки</span>
      <p>Очередь приняла 42 записи.</p></div>
  </li>
</ol>
```

Лента показывает независимые события в хронологии. Метка берёт роль состояния через локальное свойство статуса, а линия соединяет метки, а не подписи, поэтому запись любой высоты не разрывает вертикаль. Время указывается в одном формате по всей ленте.

Для конечной последовательности этапов бери [шаги](navigation.md), а не ленту: у шагов есть завершение, у ленты — нет.

Фрагмент — `timeline.html`.

## Блок кода

```html
<figure class="code-block">
  <figcaption class="code-block__head">
    <span>Ответ службы</span>
    <button class="button button--stable code-block__copy" type="button"
      data-copy="#answer" aria-pressed="false">
      <span class="button__label button__label--rest">Копировать</span>
      <span class="button__label button__label--pressed">Скопировано</span>
    </button>
  </figcaption>
  <pre id="answer"><code>craft check --surface interface</code></pre>
</figure>
```

Механика `copy.js` копирует содержимое источника и на две секунды переключает подпись кнопки. Обе подписи лежат в одной ячейке, поэтому ширина кнопки не меняется. У локального файла нет защищённого контекста, поэтому механика падает обратно на копирование через выделение.

Моноширинный шрифт остаётся только внутри блока: подпись источника набирается обычным текстом. В печати кнопка копирования скрыта.

Фрагмент — `code-block.html`.

## Таблица

Базовая таблица описана в [основном справочнике](../components.md). Дополнительно доступны три механики.

Сортировка колонки:

```html
<th aria-sort="ascending">
  <button class="data-table__sort" type="button">Задержка
    <svg class="icon" viewBox="0 0 16 16" aria-hidden="true"><path d="M8 3v10M4 9l4 4 4-4"/></svg>
  </button>
</th>
```

Атрибут `aria-sort` стоит только у той колонки, по которой набор отсортирован сейчас. Стрелка занимает место во всех заголовках, поэтому смена колонки не двигает шапку. Сортировку получает та колонка, по которой пользователь действительно ищет крайние значения.

Закреплённая шапка: `.data-table--sticky` удерживает заголовки при прокрутке длинного набора. В печати шапка возвращается в поток и повторяется на каждой странице.

Подробности строки: кнопка в строке получает `aria-expanded` и `aria-controls`, а сама подробность живёт в соседней строке `.data-table__detail`. Раскрытая строка не заменяет переход на отдельную страницу, когда данных много.
