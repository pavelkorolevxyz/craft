# Обратная связь и слои

Эти компоненты сообщают о состоянии системы и прерывают работу только тогда, когда без ответа пользователя продолжать нельзя.

## Уведомление внутри страницы

```html
<aside class="notice notice--warn" role="status">
  <span class="notice__mark" aria-hidden="true"></span>
  <div>
    <strong class="notice__title">Данные за вчера неполные</strong>
    <p>Три источника из двенадцати ещё не прислали выгрузку.</p>
  </div>
</aside>
```

Уведомление стоит рядом с тем содержимым, которого касается, а не над всей страницей. Тон отмечает квадратная метка: `.notice--ok` подтверждает результат, `.notice--warn` называет условие, о котором стоит знать, `.notice--error` сообщает о сорванном действии. Без модификатора уведомление нейтральное.

Тихий фон достаётся только ошибке. Текст остаётся нейтральным во всех тонах, а смысл несут заголовок и объяснение. Вариант `.notice--action` показывает один следующий шаг и заменяет отдельную акцентную врезку.

Если у уведомления есть действие, положи кнопки в `.notice__actions`: они встают под текстом и не спорят с меткой.

Ошибку, о которой пользователь узнаёт по итогам своего действия, объявляй через `role="alert"`, а фоновое изменение — через `role="status"`. Не объявляй заново то, что и так видно на экране.

Фрагмент — `notice.html`.

## Загрузка

Не используй универсальные серые прямоугольники. Состояние загрузки принадлежит области, которая ждёт данные: таблица сохраняет заголовки колонок и пишет «Загружаем записи», список сохраняет свою шапку, форма блокирует отправку и подписывает действие.

Область получает `aria-busy="true"`. Для длинной операции бери подписанный [ход выполнения](data.md).

## Раскрываемая область

```html
<details class="disclosure">
  <summary>
    <svg class="icon" viewBox="0 0 16 16" aria-hidden="true"><path d="m6 3 5 5-5 5"/></svg>
    Как считается задержка
  </summary>
  <div class="disclosure__body">
    <p>Медиана времени ответа за пятиминутное окно.</p>
  </div>
</details>
```

Нативный элемент сам даёт клавиатуру, поиск по странице и печать. Стрелка заменяет системный маркер и поворачивается при раскрытии.

Прячь так только уточнение. Данные, нужные для решения, остаются на виду.

## Модальное окно

```html
<button class="button" type="button" data-dialog-open="#confirm">Отозвать доступ</button>
```

Механика `dialog.js` открывает нативное окно и возвращает фокус вызвавшей кнопке после закрытия. Ловушку фокуса, клавишу выхода и затемнение держит сам элемент, поэтому отдельная реализация не нужна.

Окно уместно для подтверждения необратимого действия и короткой формы, от которой зависит продолжение работы. Справка, подробности записи и длинная форма живут на странице или в соседней области: модальное окно отрезает пользователя от контекста.

Заголовок окна называет решение, а не предмет. Кнопка подтверждения повторяет глагол действия: «Отозвать», а не «Да». Действие с потерей данных остаётся обратимым или объясняет последствие текстом.

Фрагмент — `dialog.html`.

## Пустое состояние и ошибка

`empty-state.html` объясняет, чего нет и какое действие доступно. Различай три случая: данных ещё нет, фильтр ничего не нашёл, запрос не выполнен. Первый предлагает начать, второй — ослабить условие, третий — повторить и показывает причину.

Пустое состояние не рекламирует продукт и не занимает весь экран, если рядом есть работа.
