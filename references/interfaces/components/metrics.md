# Metrics

```html
<section class="scoreboard" aria-label="Key metrics" style="--metrics: 2">
  <div class="metric"><strong class="metric__value">98.7%</strong><span class="metric__label">Successful operations</span></div>
  <div class="metric"><strong class="metric__value">12</strong><span class="metric__label">Scenarios tested</span></div>
</section>
```

`metric-strip.html` fits 2 to 4 figures that support the task. Numbers are neutral. `.metric--accent` highlights one priority figure. In a text report, 2 or 3 metrics with `.scoreboard--compact` keep the text on the first screen. A count of matching rows does not need its own metric strip.
