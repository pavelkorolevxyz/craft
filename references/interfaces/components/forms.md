# Формы и управление

Фрагмент `field.html` собирает поле целиком, примитивы темы отвечают за состояния. Управление появляется тогда, когда пользователь действительно меняет данные или параметры: отчёт обходится без формы.

## Поле

```html
<div class="field">
  <label class="field__label" for="limit">Порог оповещения</label>
  <input id="limit" name="limit" type="number" value="120"
    aria-describedby="limit-hint">
  <p class="field__hint" id="limit-hint">Значение в миллисекундах.</p>
  <p class="field__error" id="limit-error"></p>
</div>
```

Подпись стоит над управлением и связана с ним через `for`. Подсказка объясняет правило заранее и живёт в `aria-describedby`. Пустой абзац ошибки исчезает сам, поэтому разметка одинакова до и после проверки.

Ошибка появляется рядом с тем управлением, которое её вызвало, и объясняет, что сделать. При ошибке поле получает `aria-invalid="true"`, а `aria-describedby` дополняется идентификатором сообщения:

```html
<input id="limit" type="number" value="-5" aria-invalid="true"
  aria-describedby="limit-hint limit-error">
<p class="field__error" id="limit-error">Порог не может быть меньше нуля.</p>
```

Сообщение об ошибке красит роль текста, а насыщенная метка достаётся рамке поля. Не полагайся на один цвет: без текста ошибка не читается.

## Группа полей

`.form-grid` раскладывает поля в колонки по доступной ширине и собирает их в одну на узком экране. `.form-actions` держит кнопки в конце формы. Связанные флажки или радиокнопки объединяет `.field-set` с подписью в `legend`.

```html
<fieldset class="field-set">
  <legend>Что показывать</legend>
  <div class="check-group">
    <label class="check"><input type="checkbox" checked><span>Ошибки</span></label>
    <label class="check"><input type="checkbox"><span>Предупреждения</span></label>
  </div>
</fieldset>
```

## Флажок, радиокнопка, переключатель

Флажок отмечает независимые значения, радиокнопка выбирает одно из нескольких, переключатель включает режим и применяет его сразу. Если выбор вступает в силу только после подтверждения, бери флажок, а не переключатель.

```html
<label class="switch">
  <input type="checkbox" role="switch" checked>
  <span>Обновлять автоматически</span>
</label>
```

Частично выбранной группе задавай `indeterminate` у главного флажка через локальный скрипт: это состояние нельзя выразить разметкой.

Флажок и переключатель рисует тема: у нативных элементов нет общей геометрии между браузерами, а Craft держит одну толщину линии. Форму выбирает смысл, а не общий запрет на скругление. Флажок прямоугольный, потому что отмечает значение. Радиокнопка и переключатель круглые: у капсулы с круглым ползунком есть устоявшееся значение «включено или выключено», и спорить с ним ради прямых углов незачем. Прямые углы остаются у плоскостей и панелей.

## Ползунок

```html
<label class="field__label" for="window">Окно усреднения</label>
<input class="range" id="window" type="range" min="1" max="60" value="15"
  aria-describedby="window-value">
<output class="muted" id="window-value">15 минут</output>
```

Ползунок подходит приблизительному значению с наглядным диапазоном. Точное число вводят в поле. Текущее значение всегда видно рядом и обновляется вместе с ползунком.

Рельса размечена делениями по десятым долям диапазона, поэтому положение бегунка считается по шкале, а не на глаз. Бегунок круглый: за эту форму говорит привычка руки. При наведении рельса светлеет, а бегунок получает ободок из `--accent-tint`. Размер бегунка при этом не меняется, чтобы попадание курсором оставалось прежним.

## Выбор из списка

До пяти коротких вариантов — радиогруппа `.segmented`, дальше — `select` в `.select-control`. Оба варианта описаны в [основном справочнике](../components.md).

## Кнопки

`.button--primary` отмечает главное действие экрана, обычная `.button` — остальные, `.button--quiet` — третьестепенное действие рядом с содержимым. На один экран приходится одно главное действие.

Пока запрос выполняется, кнопка получает `aria-busy="true"` и не меняет размер: подпись остаётся на месте, меняется только её цвет. Если подпись всё-таки меняется, обе подписи лежат в одной ячейке через `.button--stable`.

## Состояния

Каждый элемент управления различает наведение, фокус, нажатие и недоступность. У прямоугольного поля состояние меняет его собственную рамку: наведение поднимает её до приглушённого текста, фокус красит меткой и добавляет внутреннюю линию той же краски. Второй рамки снаружи поле не получает. Мелкие элементы управления — флажок, радиокнопка, переключатель, шкала — берут общий контур фокуса страницы: внутри них рисовать линию негде. Недоступное состояние объясняется рядом текстом: одной приглушённой краски мало, чтобы понять причину.

Не отключай кнопку отправки, пока пользователь не попробовал отправить форму. Молчаливо недоступная кнопка не говорит, чего не хватает.

## Проверка на стороне страницы

Проверяй значения по событию отправки или по уходу фокуса из поля, а не на каждом нажатии клавиши. Сообщение об ошибке во время набора мешает.

После неудачной проверки переведи фокус на первое поле с ошибкой. Если ошибок несколько, добавь над формой уведомление `.notice` со списком ссылок на поля.
