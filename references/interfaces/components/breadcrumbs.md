# Breadcrumbs

```html
<nav aria-label="Path to this page">
  <ol class="breadcrumbs">
    <li><a href="#index">Reports</a></li>
    <li><a href="#weekly">Week</a></li>
    <li><span aria-current="page">Delays</span></li>
  </ol>
</nav>
```

Breadcrumbs name the page's place in a hierarchy, so the current level is plain text, not a link. Use them on a nested page. A standalone page does not need them.
