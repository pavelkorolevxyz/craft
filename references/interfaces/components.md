# Каркас и выбор компонентов

Классы находятся в `assets/interfaces/theme.css`, готовая разметка в `assets/interfaces/fragments/`. Добавляй фрагмент через `compose.py`; `--list-placeholders` показывает его подстановки. Каталог `catalog/interfaces/index.html` нужен для живого примера и подробного API выбранного компонента, не для копирования всей страницы.

## Что читать по задаче

| Задача | Справочник |
|---|---|
| Поля, кнопки, выбор значения, проверка формы | [Формы](components/forms.md) |
| Статусы, таблицы, графики, пары значений, события, код | [Данные](components/data.md) |
| Уведомление, загрузка, раскрытие, диалог, пустое состояние | [Обратная связь](components/feedback.md) |
| Вкладки, фильтры, пагинация, шаги, навигация и выбор записи | [Навигация](components/navigation.md) |

Открывай нужную ветку, не все справочники сразу. Уровни атомарной системы описаны в [правилах классификации](atomic-design.md); они нужны при расширении каталога, не для сборки обычной страницы.

## Каркас и шапка

```html
<main class="shell" data-craft-layout="interface">
  <header class="page-head">
    <div class="page-head__main">
      <h1>Название материала</h1>
      <p class="page-head__lede">Краткое пояснение.</p>
    </div>
  </header>
  <section class="section">
    <div class="section-head"><h2>Данные</h2><p>Источник и период.</p></div>
  </section>
</main>
```

`.shell` полноширинна. Для документа используй `page-head.html`, для компактной шапки с параметрами `workspace-head.html`. Пояснение стоит под заголовком, расстояние `--space-2`. Надзаголовок и отдельная колонка метаданных не входят в базовую шапку.

`section.html` создаёт самостоятельную часть с `h2`. `.section--tight` уменьшает поля для таблиц и журналов, `.section--accent` используется только для содержательного акцента. Правая колонка параметров требует отдельной локальной композиции.

## Метрики

```html
<section class="scoreboard" aria-label="Ключевые показатели" style="--metrics: 2">
  <div class="metric"><strong class="metric__value">98,7%</strong><span class="metric__label">Успешных операций</span></div>
  <div class="metric"><strong class="metric__value">12</strong><span class="metric__label">Проверенных сценариев</span></div>
</section>
```

`metric-strip.html` подходит для 2–4 величин, поддерживающих задачу. Числа нейтральны, `.metric--accent` выделяет одну приоритетную величину. В текстовом отчёте 2–3 метрики с `.scoreboard--compact` не вытесняют текст с первого экрана. Счётчик найденных строк не требует отдельной полосы метрик.

## Компоновка

Геометрию выбирай в [паттернах](patterns.md). Доступные примитивы:

| Класс | Назначение |
|---|---|
| `.split` | Неравные колонки, для другой геометрии нужен локальный класс |
| `.stack` | Вертикальная группа с `--stack-gap` |
| `.document-band` | Полноширинная полоса с полями вокруг читаемой текстовой колонки |
| `.document-block` | Самостоятельный ограниченный блок, центрированный целиком |
| `.document-block--framed` | Рамка выходит за текстовую колонку на внутренний отступ |
| `.prose` | Длина строки текста, не ограничитель рабочей поверхности |
| `.equal-panels`, `.equal-panel` | Совпадающие разделители соседних панелей через `subgrid` |

```html
<div class="equal-panels chart-grid">
  <article class="equal-panel">
    <header class="equal-panel__head">Заголовок</header>
    <div class="equal-panel__body">Содержимое</div>
    <footer class="equal-panel__foot">Итог</footer>
  </article>
</div>
```

Три зоны выравнивают только соседей одного ряда. Одиночная панель и вертикальная стопка сохраняют естественную высоту. Документные классы не применяй к дашборду или рабочему инструменту.

## Тема

Стартер уже подключает `theme.js` и кнопку темы. Сохрани их. Если нужна своя кнопка, используй `data-theme-toggle`, `aria-pressed="false"`, классы `.button--stable .button--icon .theme-switch` и две SVG-подписи `.button__label--rest`, `.button__label--pressed`. Скрипт назначит доступное имя и подсказку. Приоритеты выбора темы описаны в [грамматике](design-language.md).
