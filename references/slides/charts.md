# Графики на слайдах

Читай только если слайд содержит числовую визуализацию. Общий масштаб и роли находятся в [визуальной грамматике](design-language.md).

## Выбор и подписи

| Данные | Конструкция | Ограничение |
|---|---|---|
| Категории | `.bar-chart` | Лежащие дорожки оставляют место длинным названиям. Значение подписано у каждой строки |
| Величина по периодам | `.column-chart` | Периоды идут по времени |
| Состав периода | `.column-chart--stacked` | Части складываются в итог каждого периода |
| Два ряда по периодам | `.column-chart--grouped` | Два столбца в каждом периоде на одной шкале |
| Непрерывное изменение | `.line-chart` | Один основной ряд и не больше одного фонового; подписи у концов линий |
| Доли одного целого | `.pie-chart` | От двух до четырёх частей; не для динамики или сравнения независимых категорий |
| Два замера по категориям | `.range-chart` | Обе величины подписаны в одной строке; метка на конце "стало" различает направление без цвета |

Карта, сеть, распределение и предметная форма сигнала требуют локальной визуализации, если стандартный график теряет их смысл. Сохрани типографику, палитру, шкалы, подписи и доступное текстовое описание Craft.

- Один вывод формулирует либо заголовок, либо блок рядом. Не повторяй его в обоих местах. Блок рядом нужен для оговорки, иначе отдай графику всю ширину.
- При раскрытии вывода график с подписями уже виден на первом кадре. Если вывод находится в заголовке, показывай всё сразу.
- У графика есть доступное текстовое описание данных и вывода, источник, период и единица измерения.
- Акцент выделяет данные, доказывающие тезис. Геометрия отражает значения, а не желаемую форму.
- График начинается от левого поля слайда. У столбцов и линии подписаны обе оси; `.chart-y-axis` слева содержит пять делений от нуля до верха поля. Точное число у выбранной точки дополняет, а не заменяет шкалу.
- Разлиновки поперёк поля нет, отсчёт дают числа слева и опора внизу.

## Состав и цвет

- От двух до четырёх частей различаются ролями `--chart-series-1`…`--chart-series-4`: синий, янтарный, зелёный, тихий нейтральный. Красный остаётся смысловым акцентом. Мелкие части объединяй в остаток `.is-rest`, который нейтрален на любой позиции.
- `.chart-keys` повторяет порядок частей в HTML. Краска берётся из ряда автоматически. Ключ содержит образец, название и значение; не ставь подпись внутрь узкой доли.
- У кольца ключи стоят справа со значениями, у столбцов строкой сверху. Между ключами и графиком меньше места, чем между ключами и заголовком.
- В `.range-chart` стрелку между замерами рисует пустой `<i>` внутри `<strong>`, а не шрифтовой знак: он смещается относительно табличных цифр.

## Движение и совместимость

Движение запускает `data-reveal`, который назначает `deck.js` при раскрытии вперёд. Правило вида `[data-reveal] .блок { animation }` молчит на первом кадре, при возврате назад и в печати. Для чисел используй [счётчик](authoring.md), не отдельный скрипт.

Столбцы растут от нуля. Доли кольца вычерчиваются одновременно от собственных начал к собственным границам, не по очереди вокруг окружности. Ключи, график изменения и оси не двигаются. Не анимируй появление текста.

Проверь SVG во втором браузерном движке. Длину дуги считай в единицах `viewBox`, в CSS используй `calc(var(--value) * 1px ...)`. Начало доли задавай поворотом. Безразмерный `calc()` в геометрии SVG второй движок может проигнорировать и нарисовать целое кольцо вместо доли. Не заменяй поворот на `stroke-dashoffset`.
