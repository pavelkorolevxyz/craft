# Визуальная грамматика слайдов

Форму и сценарий выбирай в [правилах выбора](selection.md), HTML и механику бери в [механике](authoring.md). Здесь описано только оформление. Для числовой визуализации отдельно прочитай [графики](charts.md).

## Сцена и масштаб

- Фиксированная сцена 16:9, рассчитанная на проектор, телевизор и запись на телефоне. Не растягивай адаптивный интерфейс до размеров слайда.
- Страница использует нейтральный фон текущей темы либо красный акцентный. `.surface-panel` является локальной поверхностью, не третьим фоном страницы.
- Содержимое не мельче примерно `1.4cqw`. Если таблица, код или подпись не читаются при ширине сцены 390 px, раздели материал, а не уменьшай шрифт.
- Постоянные служебные элементы ограничены необязательным названием слева сверху и номером справа снизу.
- Изображение может занимать весь слайд. Подпись нужна только для контекста или указания детали.
- Показанный адрес сопровождается крупным рабочим QR-кодом. Один ресурс на слайд.

## Роли темы

Общие ограничения цвета, шрифтов и движения находятся в [идентичности](../identity.md). Локальные роли:

| Роль | Назначение |
|---|---|
| `--accent` | Читаемый красный текст |
| `--accent-mark` | Насыщенная точка, линия или контур |
| `--accent-fill` | Заливка под белым текстом |
| `.surface-accent` | Акцентная плоскость с готовой подменой тихих ролей на прозрачный белый |
| `.surface-panel`, `.surface-code` | Локальная нейтральная поверхность, фон настоящего кода |

## Типографика и композиция

| Класс | Работа |
|---|---|
| `.type-hero` | Доминирующее утверждение |
| `.type-title`, `.type-heading` | Основной и локальный заголовки |
| `.type-lede`, `.type-note` | Крупное пояснение, источник или оговорка |
| `.type-metric` | Число, которое доказывает тезис |
| `.slide-title`, `.content-block` | Заголовок слайда, локальный заголовок с пояснением |
| `.stack`, `.cluster`, `.columns` | Вертикальная группа, строка, колонки |
| `.content-aside` | Пропорция `.9fr / 1.1fr`, больше места справа |
| `.content-aside--separated` | Увеличенный промежуток, когда у основного материала уже есть подписи справа |
| `.place-center`, `.place-fill`, `.bleed-x` | Центрирование, заполнение, выход к краям |
| `.frame`, `.media-contain`, `.media-cover` | Область медиа, вписывание, заполнение с обрезкой |
| `.placeholder` | Только временная заглушка внутри `.frame`, `.photo` или `.shot` |
| `.qr`, `.qr-link` | QR-код и пара кода с адресом |

Повторяй роли, а не вводи новый кегль и вид подписи для каждой раскладки. Локальный класс меняет геометрию одной композиции. CSS живёт рядом с колодой, не в общей теме. Инлайн допускает свойства с данными вроде `style="--value:68%"`, но не раскладку.

## Содержимое

| Конструкция | Исполнение |
|---|---|
| `.bullets`, `.plain-list` | Номер в отдельной колонке для порядка речи; круг для равноправных пунктов. Общая основа строки и тонкая линия сверху, плотность через `--row-pad` |
| `.scoreboard` | Подписанные величины. Номер пункта не становится метрикой |
| `.data-table` | Общие заголовки, одинаковая структура строк, точные значения. Числа и их заголовки выравниваются одинаково |
| `.steps` | Нумерованные действия без временной шкалы |
| `.timeline` | События с датами или периодами; `.is-current` означает реальное текущее состояние, не порядковую позицию |
| `.flow` | Равные прямоугольные узлы с одной строкой по центру; связь заполняет промежуток, наконечник упирается в грань узла |
| `.s-visual-compare` | Два сопоставимых изображения, подписи сверху, общий масштаб |
| `.code` | Читаемый исходник с подсветкой строк аргумента |

Узлы `.flow-node` по умолчанию нейтральны. `.flow-node--accent` даёт постоянную заливку, а не движущийся фокус; условия применения находятся в [правилах выбора](selection.md). Раскрытие `.frag` описано там же и в [механике](authoring.md), не назначай его по внешнему виду примера.

## Файлы

`base.css` хранит сцену и печать, `theme.css` хранит роли и композиции, `deck.js` хранит навигацию и раскрытие. Все три лежат в `assets/slides/`. Стартовые фрагменты лежат в `assets/slides/fragments/`, их контракты выдаёт `compose.py --list-placeholders`. `craft.json` хранит реестр, читать его целиком для одной колоды не нужно.
