# Создание презентации Craft

## Начало работы

```bash
python3 {{skill_path}}/scripts/scaffold.py <целевая-папка> --surface slides --title "Название доклада"
```

Открой `index.html` напрямую. Стрелки или пробел переключают страницы, `G` открывает обзор сеткой, `L` — обзор лентой, `F` — полноэкранный режим, `H` — справку по управлению.

## Структура доклада

1. Сформулируй одним предложением мысль, которую аудитория должна повторить на следующий день.
2. Раздели доклад на аргументы в её поддержку.
3. Дай каждому слайду одну задачу: тезис, доказательство, демонстрацию, переход или ресурс.
4. Представь докладчика в начале, до технического контекста.
5. Заверши выводами, ресурсами и контактами.

Подкрепляй технический рассказ скриншотами, демонстрациями и схемами. Не добавляй к ним декоративные подписи, если содержание понятно без них.

## Каркас слайда

```html
<section class="slide custom-flow">
  <div class="pad">
    <p class="slide-title">Путь запроса</p>
    <div class="custom-flow__diagram">...</div>
    <p class="type-note">Что должна заметить аудитория</p>
  </div>
  <p class="slide-number"></p>
</section>
```

Для композиции конкретного доклада используй локальный класс наподобие `.custom-flow`. Не добавляй разовую раскладку в общую тему.

## Фрагменты

```html
<ul class="bullets">
  <li class="frag" data-n="01"><div><h3>Первый тезис</h3></div></li>
  <li class="frag" data-n="02"><div><h3>Второй тезис</h3></div></li>
</ul>
```

`deck.js` создаёт отдельную пронумерованную страницу для каждого шага раскрытия. Исходный слайд пишется один раз.

## Счётчик показателя

Конечное значение оставляй в тексте. `deck.js` запустит счёт от нуля только при раскрытии вперёд. Суффикс, десятичная запятая и пробелы между разрядами сохраняются.

```html
<div class="frag">
  <p class="type-metric" data-count data-count-duration="1200">24%</p>
</div>
```

`data-count-duration` задаёт длительность в миллисекундах. Без него счёт занимает 900 мс. При уменьшении движения, печати, прямой ссылке и возврате назад сразу видно конечное значение.

## Код

```html
<pre class="code" data-language="javascript" data-highlight-lines="2-3"><code>function example(input) {
    return transform(input);
}</code></pre>
```

Не пиши синтаксические элементы `<span>` вручную. Локальная подсветка выполняется до раскрытия фрагментов.

## Проверка

Просмотри колоду в обычном режиме, сетке и ленте. Затем напечатай в PDF и проверь количество страниц, фоны, код, скриншоты и QR-коды. Испытай как минимум область 1280×720 и узкую область размером с запись на телефоне.
