# Идентичность Craft

Общие правила для всех носителей. Размеры и взаимодействие определяет выбранный формат.

## Визуальный язык

- Нейтральные светлая и тёмная поверхности, красный фирменный акцент, прямоугольные панели и линии толщиной 1 px.
- Geologica в заголовках и значимых числах, Onest в тексте и управлении, моноширинный шрифт только в коде.
- Красный допустим как фон и графический мотив. Выделение одного элемента среди данных должно иметь смысловое основание.
- Насыщенные дополнительные цвета обозначают данные или статусы, а не украшают страницу. Цвет не является единственным носителем смысла.
- Сигнальный цвет получает метка, текст рядом остаётся нейтральным. Исключения конкретного формата описаны в его грамматике.
- На акцентной заливке используй `--craft-on-accent-*`, а не готовый серый. Прозрачные тихие роли сохраняют тон подложки.
- Рамка имеет четыре стороны. Разделитель имеет одну. Общая граница не дублируется.
- Не добавляй декоративные градиенты, свечение, стекло, тени, скруглённые панели, повторяющиеся карточки с иконками и стилизацию под терминал. Технические слои фоновой краски уже определены темой, не переписывай их ради этого ограничения.
- Не набирай служебные подписи капсом и с разрядкой.
- Анимация допустима только как короткий однократный акцент на графике или величине. Текст, раскладка, переходы страниц и декоративные циклы не анимируются. Учитывай `prefers-reduced-motion`.

## Токены

Источник значений: `assets/shared/tokens.css`. Используй роли, не копируй значения цветов в локальный CSS.

| Назначение | Общие роли |
|---|---|
| Поверхности | `--craft-bg`, `--craft-surface`, `--craft-surface-muted`, `--craft-sunken` |
| Текст и линии | `--craft-text`, `--craft-text-body`, `--craft-muted`, `--craft-line`, `--craft-line-strong` |
| Акцент | `--craft-accent` для текста, `--craft-accent-mark` для метки, `--craft-accent-fill` для заливки, `--craft-accent-tint` для тихого фона |
| На акценте | `--craft-on-accent`, `--craft-on-accent-muted`, `--craft-on-accent-line`, `--craft-on-accent-disabled` |
| Состояния | `--craft-ok`, `--craft-warn`, `--craft-error` |
| Ряды данных | `--craft-data-red`, `--craft-data-neutral`, `--craft-data-blue`, `--craft-data-amber`, `--craft-data-green` |
| Шрифты | `--craft-font-display`, `--craft-font-text`, `--craft-font-mono` |

Тема формата сопоставляет `--craft-*` с локальными ролями. Не переноси размеры интерфейса на слайд или компоненты между носителями только из-за общего цвета.
