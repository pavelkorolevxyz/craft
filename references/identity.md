# Идентичность Craft

Craft хранит общие визуальные решения для интерфейсов, презентаций и других форматов.

## Характер

Собирай материал под конкретную задачу. Не имитируй терминал, не перегружай страницу акцентами и не повторяй логотип без необходимости.

Стиль задают:

- тёмные спокойные поверхности;
- Geologica в коротких заголовках и значимых числах;
- Onest в тексте для чтения и элементах управления;
- красный для действия, текущего состояния или намеренно акцентной поверхности;
- прямоугольная геометрия и точная структура линий толщиной 1 px;
- плотность информации, соответствующая носителю;
- короткие формулировки и реальные данные без текста для заполнения места.

## Общие токены

Единый источник — `assets/shared/tokens.css`:

- `--craft-bg`, `--craft-surface`, `--craft-surface-muted`, `--craft-sunken`;
- `--craft-line`, `--craft-line-strong`;
- `--craft-text`, `--craft-text-body`, `--craft-muted`;
- `--craft-accent`, `--craft-accent-base`, `--craft-accent-fill`;
- `--craft-good`, `--craft-warn`, `--craft-bad`;
- `--craft-font-display`, `--craft-font-text`, `--craft-font-mono`.

Каждый формат сопоставляет эти значения со своими локальными ролями. Не заставляй интерфейсные и слайдовые компоненты делить размеры: идентичность общая, эргономика разная.

## Общие законы

- Используй реальные данные. Не выдумывай правдоподобные показатели, отзывы, источники и состояния системы.
- Красный обозначает действие, текущее состояние или важный сигнал. Не выделяй ряд чисел, если среди них нет приоритетного.
- Моноширинный шрифт используется только для настоящего кода.
- Избегай верхнего регистра и разреженных микроподписей.
- Никаких градиентов, свечения, стекла, декоративных теней, скруглённых SaaS-карточек и повторяющихся сеток из иконок с текстом.
- Полная рамка состоит из четырёх сторон. Две соседние или три стороны — ошибка. Верхняя и нижняя границы допустимы у строк списка. Общая граница никогда не дублируется.
- Цвет не бывает единственным носителем смысла.
- Внешние зависимости подключаются только осознанно. По умолчанию результат работает через `file://` без сборки.
- Проектируй доступность, клавиатурное управление, уменьшение движения и вывод в печать или PDF вместе с остальным интерфейсом.

## Самостоятельность форматов

Каждый формат определяет собственную композицию, масштаб и механику:

- интерфейсы плотные, адаптивные и подчинены задаче;
- слайды имеют формат 16:9, читаются на проекторе и раскрывают одну мысль за раз;
- для нового формата сначала опиши условия просмотра, затем решай, какие компоненты можно перенести.

При добавлении формата сначала используй общие токены и законы. Переиспользуй компоненты только тогда, когда взаимодействие и условия просмотра действительно совпадают.
