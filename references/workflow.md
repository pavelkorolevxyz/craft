# Рабочий процесс Craft

## До HTML

Определи аудиторию, задачу, реальные данные и ожидаемое действие или вывод. Форму слайда выбирай по [отношению данных и сценарию показа](slides/selection.md), геометрию страницы по [паттернам интерфейсов](interfaces/patterns.md).

Используй данные пользователя. Не выдумывай показатели, причины, отзывы, источники и состояния системы. Если данных не хватает, обозначь отсутствие или спроси. Каждое самостоятельное значение имеет свою подпись: не склеивай категорию, состояние и длительность в одну строку.

## Создание и композиция

Все пути команд ниже относительны корню навыка. Подставь абсолютный путь к нему, если работаешь в другой папке.

```bash
python3 scripts/scaffold.py <целевая-папка> --surface interface --title "Название"
# Для колоды используй --surface slides
python3 scripts/compose.py <целевая-папка> --list-fragments
python3 scripts/compose.py <целевая-папка> --fragment <id> --list-placeholders
```

До скаффолда выясни доставку результата:

- `--delivery local` (по умолчанию) — все ресурсы в папке проекта, работает через `file://` без сети. Валидатор запрещает любой внешний ресурс.
- `--delivery web` — для публикации в интернете. Шрифты подключаются с Google Fonts, локальные woff2 не копируются. Валидатор допускает только https-ресурсы с `fonts.googleapis.com`, `fonts.gstatic.com`, `cdn.jsdelivr.net`, `unpkg.com`; версии пакетов с CDN закрепляй в URL.

Если нужен ровно один файл без папки ресурсов, собери готовый локальный проект в один HTML: CSS, скрипты, шрифты и фавикон встраиваются внутрь (интерфейс около 200 КБ, колода около 360 КБ). Собирай после всех правок и проверь результат отдельно:

```bash
python3 scripts/bundle.py <целевая-папка>              # создаёт index.single.html
python3 scripts/check_project.py <папка-с-одним-файлом>  # файл переименован в index.html
```

Стартер пуст и не перезаписывает непустую папку. Внешний источник вне белого списка доставки `web` согласуй заранее.

Добавляй подходящий зарегистрированный фрагмент через `compose.py`. Текст передавай через `--set`, доверенную разметку через `--html` или `--html-file`. `--dry-run` проверяет и выводит фрагмент без записи. Скрипт экранирует текст, проверяет типы и коллизии `id`, подключает зависимости.

Сначала используй фрагмент, затем примитив темы, затем локальный CSS. Не деформируй материал под неподходящий шаблон. Не копируй каталог целиком и не редактируй общую тему ради одной страницы. Сохраняй `data-craft-layout`, `data-slide-layout` и атрибуты состояния.

Перед сдачей убери текст для заполнения места, рекламные оценки и выводы без данных. Оставь термины и оговорки, влияющие на смысл.

## Проверка

```bash
python3 scripts/check_project.py <целевая-папка>
```

Нужен Chromium, путь к нему можно задать через `CHROMIUM`. Режим `--static-only` проверяет только исходники и ресурсы, не подтверждает готовность материала. Полный валидатор проверяет автономность, структуру, переполнение на 1440, 390 и 320 px, имена управления, тему, состояние колоды и создание PDF.

После валидатора самостоятельно проверь результат в браузере:

| Материал | Что проверить сверх автоматики |
|---|---|
| Интерфейс | Обе темы на 1440×900, 390×844 и 320 px; реальную работу поиска, фильтров и действий мышью и клавиатурой; фокус, выбор, ошибки и пустой результат; стабильность размеров управления |
| Слайды | 1280×720 и запись на телефоне; каждое раскрытие вперёд и назад, прямые ссылки, сетку, ленту, полный экран; первый и промежуточные кадры по плану; основания сравнений, стрелок и акцентов |
| Оба формата | Уменьшение движения; читаемость и контраст; PDF без обрезаний, пустых хвостов и пропавших данных |

У слайдов число страниц PDF совпадает с числом экранных состояний. У интерфейса печатаются данные и подписи, не бесполезное на бумаге управление. Правила печатной раскладки находятся в грамматике формата.

Сохрани снимки, PDF и точные команды проверок. Если браузерная или визуальная проверка недоступна, назови это ограничение. Самоотчёт агента и успешный валидатор не заменяют просмотр содержимого.
